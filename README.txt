SHADOW STRIKE — Mobile FPS browser prototype

Main game file: index.html

To publish with GitHub Pages:
1. Open your public repository on github.com.
2. Choose Add file > Upload files.
3. Upload index.html from this folder (or upload the ZIP and extract it first; GitHub Pages needs index.html at the repository root).
4. Commit changes.
5. Open repository Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. Wait for the Pages URL to appear on the Pages settings screen.

This is a 2D-drawn browser shooter prototype, not a full 3D online multiplayer game.
